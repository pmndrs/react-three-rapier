<Intro>
  `@react-three/rapier` (or `r3/rapier`) is a wrapper around the [Rapier](https://rapier.rs/docs/user_guides/javascript)
  WASM-based physics engine, designed to slot seamlessly into a
  [react-three-fiber](https://github.com/pmndrs/react-three-fiber) pipeline. Wrap a mesh in `<RigidBody>` and it falls.
</Intro>

The goal of this library is to provide a fast physics engine with minimal friction and a small, straightforward API.

```bash
npm install @react-three/rapier
```

```tsx
import { Canvas } from "@react-three/fiber";
import { Physics, RigidBody, CuboidCollider } from "@react-three/rapier";

export default function App() {
  return (
    <Canvas>
      <Suspense>
        <Physics debug>
          <RigidBody colliders="hull" restitution={2}>
            <mesh>
              <torusGeometry />
              <meshStandardMaterial />
            </mesh>
          </RigidBody>

          <CuboidCollider position={[0, -2, 0]} args={[20, 0.5, 20]} />
        </Physics>
      </Suspense>
    </Canvas>
  );
}
```

## What you get

- Automatic colliders generated from your meshes, or hand-placed colliders for compound shapes ([RigidBody](/api/rigid-body), [Colliders](/api/colliders)).
- Instanced meshes with one body per instance ([InstancedRigidBodies](/api/instanced-rigid-bodies)).
- Joints as hooks ([Joints](/api/joints)).
- Collision, intersection and contact-force events, collision groups and physics hooks ([Advanced](/advanced/collision-events)).
- Direct access to the Rapier `world` for queries such as raycasts ([Hooks](/api/hooks)).
- Physics stepped at a fixed rate on the react-three-fiber v10 scheduler, with interpolation ([Update loop](/advanced/update-loop)).
- A kinematic [character controller](/api/character-controller) and [soft bodies](/api/soft-bodies) (cloth, ropes, jelly).
- A debug renderer ([Debug](/api/debug)) and an [Attractor](/api/attractors) addon.
