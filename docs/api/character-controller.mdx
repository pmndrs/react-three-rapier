A kinematic character controller moves a body through the world while resolving collisions itself: it slides along
walls, climbs slopes up to a maximum angle, steps up stairs and snaps to the ground. `@react-three/rapier` wraps
Rapier's `KinematicCharacterController` in two APIs:

- `<CharacterController>`: a `kinematicPosition` `<RigidBody>` you give a velocity to. The easiest way to get started.
- `useCharacterController`: creates and owns the Rapier controller and gives you a `move()` function for your own body.

Both apply the motion once per fixed physics step, with the step's `dt`, so movement is framerate independent. Gravity,
jumping and input are left to you.

## `<CharacterController>`

```tsx
import { useRef } from "react";
import {
  CapsuleCollider,
  CharacterController,
  CharacterControllerRef,
  useBeforePhysicsStep
} from "@react-three/rapier";

const Player = () => {
  const ref = useRef<CharacterControllerRef>(null);
  const vy = useRef(0);
  const input = useInput(); // your own input, returns { x, z, jump }

  useBeforePhysicsStep((_world, dt) => {
    const c = ref.current!;
    vy.current = c.grounded && !input.jump ? 0 : vy.current - 9.81 * dt;
    if (c.grounded && input.jump) vy.current = 6;
    c.setVelocity({ x: input.x * 4, y: vy.current, z: input.z * 4 });
  });

  return (
    <CharacterController
      ref={ref}
      position={[0, 2, 0]}
      autostep={{ maxHeight: 0.3, minWidth: 0.2 }}
      snapToGround={0.2}
      onGrounded={() => console.log("landed")}
    >
      <CapsuleCollider args={[0.5, 0.3]} />
    </CharacterController>
  );
};
```

Children are colliders and meshes, exactly like `<RigidBody>`. The first non-sensor collider is used to compute the
movement. `<CharacterController>` defaults to `colliders={false}`, so add an explicit collider (a capsule is the usual
choice), or pass `colliders` to generate one.

It accepts every [controller option](#options), every `<RigidBody>` prop except `type`, and:

| prop                   | description                                                                                                            |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `onGrounded`           | Called once when the character lands (edge triggered).                                                                 |
| `onAirborne`           | Called once when the character leaves the ground (edge triggered).                                                     |
| `onCharacterCollision` | Called for every collision found while moving, on every step. The collision object is pooled: read it, do not keep it. |
| `filterFlags`          | Rapier `QueryFilterFlags` used while moving.                                                                           |
| `filterGroups`         | Rapier interaction groups: only matching colliders are considered.                                                     |
| `filterPredicate`      | `(collider) => boolean`. Return `false` to ignore a collider. The character's own colliders are always ignored.        |
| `excludeSensors`       | Ignore sensor colliders. Default `true`.                                                                               |

### Ref

The ref (`CharacterControllerRef`) exposes:

| member             | description                                                                                                                         |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------- |
| `controller`       | The Rapier `KinematicCharacterController`.                                                                                          |
| `rigidBody`        | The character's kinematic rigid body.                                                                                               |
| `grounded`         | Whether the character stood on the ground during the last step.                                                                     |
| `setVelocity(v)`   | Sets the persistent desired velocity in units per second. It is scaled by `dt` on every step.                                       |
| `translate(delta)` | Queues a one-off displacement applied on the next step, on top of the velocity (knockback, pushes). Calls before a step accumulate. |

> [!NOTE]
> The component registers its step callback in its own effect, which runs before callbacks registered by a parent
> component. A `setVelocity` / `translate` from your `useBeforePhysicsStep` in a parent is therefore applied on the next
> step (one fixed step of latency), and `grounded` reflects the previous step.

## `useCharacterController`

Use the hook when you want to drive your own `<RigidBody>`. It creates the controller on mount and frees it on unmount
(StrictMode safe), applies options reactively, and returns a referentially stable api:

```tsx
import { useRef } from "react";
import {
  CapsuleCollider,
  RapierRigidBody,
  RigidBody,
  useBeforePhysicsStep,
  useCharacterController
} from "@react-three/rapier";

const Player = () => {
  const body = useRef<RapierRigidBody>(null);
  const vy = useRef(0);
  const cc = useCharacterController({
    autostep: { maxHeight: 0.3, minWidth: 0.2 }
  });

  useBeforePhysicsStep((_world, dt) => {
    vy.current -= 9.81 * dt;
    const { grounded } = cc.move(body.current!, {
      x: 0,
      y: vy.current * dt,
      z: 0
    });
    if (grounded) vy.current = 0;
  });

  return (
    <RigidBody ref={body} type="kinematicPosition" colliders={false}>
      <CapsuleCollider args={[0.5, 0.3]} />
    </RigidBody>
  );
};
```

`move(rigidBody, desiredTranslation, options?)` computes the collision-resolved movement for that step, applies it with
`setNextKinematicTranslation` and returns `{ movement, grounded, collisions }`. Call it once per step from
`useBeforePhysicsStep`, with a translation already scaled by `dt`. The result object (including `movement` and
`collisions`) is reused between calls: read it, do not keep it.

`options` takes `collider` (defaults to the body's first non-sensor collider), `filterFlags`, `filterGroups`,
`filterPredicate` and `excludeSensors` (default `true`), with the same meaning as the component props above.

`controller` is the underlying Rapier controller, valid while the hook is mounted. Calling `move` after unmount is a
no-op that warns in development.

## Options

Shared by `<CharacterController>` and `useCharacterController`. Every option is applied reactively. Options left
`undefined` (or changed back to `undefined`) use Rapier's defaults.

| option                         | default        | description                                                                   |
| ------------------------------ | -------------- | ----------------------------------------------------------------------------- |
| `offset`                       | `0.01`         | Small gap kept between the character and the environment.                     |
| `up`                           | `[0, 1, 0]`    | The character's up direction (`[x, y, z]` or `{ x, y, z }`).                  |
| `slide`                        | `true`         | Slide along obstacles instead of stopping.                                    |
| `maxSlopeClimbAngle`           | Rapier default | Steepest slope the character can climb, in radians.                           |
| `minSlopeSlideAngle`           | Rapier default | Slope angle, in radians, from which the character slides down.                |
| `autostep`                     | disabled       | `{ maxHeight, minWidth, includeDynamicBodies? }` to climb stairs, or `false`. |
| `snapToGround`                 | disabled       | Maximum distance to snap down to the ground (stairs, slopes), or `false`.     |
| `applyImpulsesToDynamicBodies` | Rapier default | Push dynamic bodies the character walks into.                                 |
| `characterMass`                | Rapier default | Mass used when pushing dynamic bodies.                                        |
| `normalNudgeFactor`            | Rapier default | See Rapier's docs.                                                            |

## Notes

- A kinematic body is never pushed out of other colliders by contacts. The controller is what keeps it out of walls,
  so move the character only through `move()` / `setVelocity()`.
- Steps run at the fixed `timeStep`, and the rendered body is [interpolated](/advanced/update-loop#interpolation)
  between steps like any other body.
- The `character-controller` demo shows stairs, slopes, jumping and pushing balls.
